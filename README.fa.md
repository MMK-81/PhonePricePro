# قیمت یار (PhonePricePro)

برنامه ویندوزی برای استخراج قیمت گوشی از سایت هایی که آدرسشان را می دهید و تحویل فایل اکسل، با رابط گرافیکی مدرن و آپدیت خودکار از GitHub Releases.

**سازنده: محمد مهدی کاشی** — نسخه 1.0.0

## امکانات

- رابط گرافیکی تیره و مدرن (CustomTkinter) با نمایش نام سازنده در داخل برنامه
- استخراج قیمت از هر لینکی که وارد می کنید (دیجی کالا، تکنولایف، همراه تل و هر سایت دلخواه)
- استخراج رنگ ها و قیمت هر رنگ از JSON-LD، __NEXT_DATA__، انتخابگر CSS و متن صفحه
- استخراج هیبریدی: ابتدا درخواست HTTP سریع، سپس مرورگر مخفی (Edge/Chrome نصب شده) در صورت مسدود شدن
- خروجی اکسل سه برگه: قیمت ها، خلاصه (با نمودار)، و گزارش اجرا — با چیدمان راست به چپ
- آپدیت خودکار از GitHub Releases (نسخه پرتابل جایگزین می شود یا نصب کننده اجرا می گردد)
- تنظیم انتخابگرهای هر سایت از داخل برنامه بدون نیاز به ویرایش کد

## اجرا از سورس

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

برای پشتیبانی مرورگر مخفی، نصب Microsoft Edge یا Chrome کافی است. در صورت عدم وجود آنها می توانید
`python -m playwright install chromium` را هم اجرا کنید (در برخی کشورها دانلود آن مسدود است).

## ساخت exe پرتابل

```bat
build.bat
```
خروجی: `dist\PhonePricePro\PhonePricePro.exe`

## ساخت نصب کننده

پس از ساخت پرتابل، با Inno Setup 6 (معمولاً نصب شده در مسیر کاربر یا Program Files):

```bat
ISCC.exe installer.iss
```
خروجی: `installer_output\PhonePricePro_Setup.exe`

## آپدیت

در تب «آپدیت و درباره» یا تب «تنظیمات سایت ها»، آدرس مخزن GitHub را وارد کنید (مثلاً `USER/REPO`). سپس دکمه «بررسی آپدیت» را بزنید:

- فایل `.zip`: نسخه پرتابل به طور ایمن جایگزین می شود.
- فایل `.exe`: نصب کننده دانلود و اجرا می شود.

برای انتشار نسخه جدید:
1. `VERSION` را در `app/config.py` و نسخه را در `installer.iss` تغییر دهید.
2. exe پرتابل و نصب کننده را بسازید.
3. در GitHub یک Release با tag همان نسخه (مثلاً `v1.0.1`) ایجاد و فایل ها را ضمیمه کنید.
